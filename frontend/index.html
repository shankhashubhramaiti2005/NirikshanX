About NirikshanX
AI-Powered Packaged Commodity Compliance System
v1.0.0 — DEMO

NirikshanX is an intelligent compliance verification system designed for enforcement officers, inspectors, manufacturers, retailers, and consumers to verify that packaged products comply with India's Legal Metrology (Packaged Commodities) Rules, 2011. It uses a demo AI pipeline to extract mandatory declarations, validate them against the rule engine, and generate evidence-backed compliance reports.

🔬 Core Features

  • AI-powered label image analysis with mock OCR pipeline
  • Configurable rule engine based on LM (PC) Rules 2011
  • 3 deterministic demo scenarios (Compliant / Missing / Multi-violation)
  • Confidence scoring with REVIEW_REQUIRED thresholds
  • Field-level evidence per violation
  • PDF compliance report generation
  • Role-Based Access Control (5 roles)
  • Real-time dashboard with live DB statistics

🏗️ Technology Stack

  • Backend: FastAPI 0.111 + SQLAlchemy 2.0 (SQLite)
  • Auth: JWT Bearer + bcrypt 5.x password hashing
  • AI: Demo deterministic pipeline (no GPU/model needed)
  • Reports: ReportLab PDF generation
  • Frontend: Vanilla HTML5/CSS3/ES2022
  • Charts: Chart.js 4.4
  • Python: 3.13 (Windows)
  • API Docs: http://localhost:8000/docs

👥 User Roles

  • ADMIN — Full system access
  • ENFORCEMENT_OFFICER — View all scans, initiate cases
  • INSPECTOR — Scan products, review findings
  • MANUFACTURER — View own product scans
  • CONSUMER — Submit complaints, view results

🚀 Roadmap

  • Real PaddleOCR integration (CRNN + detection)
  • YOLOv11 object detection for label regions
  • Alembic database migrations
  • Case management & audit logs

⚠️ Legal Disclaimer: NirikshanX AI findings are indicative and must be reviewed by a qualified Legal Metrology officer before any enforcement action. The system does not constitute a legally binding determination of compliance or non-compliance.
